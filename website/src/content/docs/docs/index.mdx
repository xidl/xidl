This page introduces the core elements of the XIDL language: basic and
container types, structs, enums, interfaces, and unions.

## Basic Types

The following basic types are available:

| Type Name | Description |
| --- | --- |
| uint8 | 8-bit unsigned integer |
| uint16 | 16-bit unsigned integer |
| uint32 | 32-bit unsigned integer |
| uint64 | 64-bit unsigned integer |
| int8 | 8-bit signed integer |
| int16 | 16-bit signed integer |
| int32 | 32-bit signed integer |
| int64 | 64-bit signed integer |
| float32 | 32-bit single-precision floating-point number |
| float64 | 64-bit double-precision floating-point number |
| boolean | Boolean value |
| string | String |

## Container Types

| Type Name | Description |
| --- | --- |
| sequence\<T> | Variable-length array with elements of type T |
| map\<K, V> | Key-value pair collection with keys of type K and values of type V |

## Structs

```idl
struct Point {
    uint32 x;
    uint32 y;
};
```

### Struct Inheritance

A struct may inherit from exactly one other struct. Inheritance is a data
contract, not a class hierarchy: the base members are flattened into the
derived struct's JSON shape.

```idl
struct UserRef {
    string id;
};

struct Participant : UserRef {
    string role;
};
```

Both `UserRef` and `Participant` serialize `id` at the top level. A
`Participant` value is `{ "id": "...", "role": "..." }`, never
`{ "base": { "id": "..." }, "role": "..." }`.

The rules are:

- A struct has at most one base struct.
- The base must be a complete struct declaration.
- An inheritance cycle is rejected.
- A derived struct may not declare a field that an ancestor already declares.
- `@rename`, `@rename_all`, `@optional`, and `@skip` on base fields keep their
  meaning in the derived wire shape.

Targets keep their native type relation while using the same flat JSON shape:
Rust stores the base in a flattened `base` field, TypeScript uses `extends`,
Go embeds the base struct, OpenAPI emits an `allOf` composition, and the
remaining JSON schemas and validators declare the inherited members directly.
Version adapters treat a changed inherited model as an explicit application
decision and require a conversion hook instead of guessing a field layout.

```idl
enum Color {
    Red,

};
```

## Interfaces

```idl
interface ILogger {
    void log(string message);
};
```

## Union

```idl
enum Color {
    Red,
    Green,
    Blue
};

union ColorPoint switch(Color) {
    case Red:
        uint32 red_x;
        uint32 red_y;
    case Green:
        uint32 green_x;
        uint32 green_y;
    case Blue:
        uint32 blue_x;
        uint32 blue_y;
    default:
        uint32 default_x;
        uint32 default_y;
};
```
