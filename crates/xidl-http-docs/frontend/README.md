# Generated HTTP reference

This Starlight project is generated by XIDL. It contains framework
configuration, Markdown pages in `src/content/docs/` and plain Markdown/AI
indexes in `public/`.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm dev
```

Use Node.js 24+ and pnpm 11+. Deploy `dist/` at the configured base URL. The
built site is static; the deployed server does not need Node.js. Change
publication settings in `xidl-http-docs.toml` and regenerate. Generated paths
are owned by the compiler; place hand-authored pages at separate paths.

Each published API version has a Scalar playground and a self-contained OpenAPI
download. Build/dev copies the pinned Scalar browser bundle and its MIT license
to public/_scalar; generated bundles are not part of the Rust package. Scalar
uses local assets, disables proxy/agent/telemetry/persisted authentication, and
sends requests only when the reader chooses to send. APIs must allow this site's
origin through CORS. Playground navigation uses Starlight's route middleware.

Starlight owns the site theme. The Head wrapper preserves its native metadata
and loads a small adapter for Scalar's public mode classes, including open API
clients. Theme preferences and system-mode handling stay with Starlight.
